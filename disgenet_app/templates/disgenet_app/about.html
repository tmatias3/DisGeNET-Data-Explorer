The Project

What is DisGeNET Cube?

This project is part of the Sistemas de Bases de Dados course at the Universidade de Aveiro. It implements a full ETL pipeline from the original SQLite DisGeNET 2020 database into a SQL Server data warehouse optimised for analytical queries.

The warehouse follows a star schema with two fact tables and five dimension tables, enabling efficient multidimensional analysis across genes, diseases, variants, sources, and time.
